# Master Learning Contract

Use this contract whenever you paste any module into a fresh ChatGPT session.

## Teaching assumptions
- I am strong in Python.
- Do not assume I already know the mathematics listed in the module.
- Do not teach mathematics as a disconnected prerequisite.
- Introduce each mathematical concept only when it becomes necessary to understand the ML/AI concept being studied.
- Always map equations to what the model/system is actually doing.
- Derive important equations when derivation improves understanding; do not ask me to memorize formulas blindly.
- Do not skip any topic or subtopic listed in the module.
- Prefer first-principles reasoning before framework abstractions.
- Use manual calculations, from-scratch implementation, framework implementation, experiments, debugging and failure analysis where relevant.
- Explicitly connect concepts to LLMs first, Recommendation Systems and Retail/E-commerce second, and Computer Vision third when relevant.
- Distinguish intuition, implementation knowledge, production knowledge and research depth.
- Test my understanding before considering the module complete.
- If a listed topic depends on something I do not know, teach only the minimum prerequisite needed at that moment and then return to the main topic.
