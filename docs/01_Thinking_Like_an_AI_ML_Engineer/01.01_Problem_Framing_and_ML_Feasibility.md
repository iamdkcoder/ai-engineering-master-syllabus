# 01.01 Problem Framing and ML Feasibility

**Priority:** P0

**Use with:** `00_Curriculum_System/00.01_Master_Learning_Prompt.md`

## Topic and Subtopic Inventory
- Business objective vs ML objective
- Decision to be improved
- Stakeholders and users
- Prediction vs ranking vs generation vs optimization vs control
- When rules are better than ML
- When retrieval/search is better than generation
- When causal inference is required instead of prediction
- Actionability of predictions
- Cost of errors
- Operational constraints
- Latency/throughput/cost/privacy constraints
- Success criteria
- Baseline-first thinking
- Problem decomposition
- Unknown-unknowns and assumption logging

## Just-in-Time Mathematics / Foundations
- Expected value intuition
- Basic probability for uncertainty
- Cost/utility functions

## Required Learning Modes
- First-principles intuition
- Manual or toy calculation where meaningful
- From-scratch implementation where educationally useful
- Standard-library/framework implementation
- Experiments and ablations
- Failure-mode and debugging analysis
- Production/system implications where relevant
- Mastery questions before completion

- P0: reach L5 (Design)
- P1: reach L4-L5 (Diagnose/Design)
- P2: reach L3-L4 (Build/Diagnose)
