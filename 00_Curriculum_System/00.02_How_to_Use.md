# How to Use This Repository

This repository is a **syllabus inventory**, not a textbook.

## Workflow
1. Follow the numbered folders in order unless a module explicitly says it can be studied independently.
2. Open one module file.
3. Copy the **Master Learning Contract** plus the complete module file into a fresh ChatGPT session.
4. Ask ChatGPT to teach the module interactively and not skip any listed subtopic.
5. Mark the module complete only after theory, implementation, experiments and mastery checks are done.
6. Revisit repeated mathematical ideas in their new context instead of treating them as "already finished".

## Design principle
Mathematics is **just-in-time**. There is no standalone mathematics prerequisite phase. Math appears inside the ML/AI problem where it is actually used.

## Priority
- P0 — Core: must know deeply.
- P1 — Senior-level: should know well.
- P2 — Advanced/specialized: learn after P0/P1 or when the specialization requires it.
- P3 — Research/optional depth.
