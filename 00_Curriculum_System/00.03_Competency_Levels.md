# Competency Levels

Use these levels to track each module.

- **L0 — Recognition:** I know the term.
- **L1 — Explain:** I can explain the intuition in my own words.
- **L2 — Use:** I can use the concept correctly with standard libraries/frameworks.
- **L3 — Build:** I can implement a simplified version from first principles.
- **L4 — Diagnose:** I can debug failure modes and reason about trade-offs.
- **L5 — Design:** I can decide when to use or not use it in an unfamiliar real-world problem.
- **L6 — Lead/Research:** I can compare alternatives, design experiments, defend architecture decisions and read/implement research-level variations.

Target:
- P0 topics: L5
- P1 topics: L4-L5
- P2 topics: L3-L4
- P3 topics: awareness or research depth as needed
